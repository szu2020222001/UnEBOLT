三种基础损失的计算

以下省略唯一的频段轴。yn,e 为第 n 个连续 EEG 标签窗口、第 e 条连接的真实 PLV，ŷn,e 为预测；n=1,…,B，e=1,…,E。所有求和只使用非对角上三角连接。

① 数值误差 LMSE

LMSE = (1 / BE) ∑n=1…B ∑e=1…E (ŷn,e − yn,e)²

对窗口和连接等权，约束 PLV 绝对数值。

② 时间相关损失 Lcorr

an,e = ŷn,e − meann(ŷn,e)，　bn,e = yn,e − meann(yn,e)
v̂e = meann(an,e²)，　ve = meann(bn,e²)
r̃e = meann(an,ebn,e) / √[(v̂e + ε)(ve + ε)]
V = {e : ve > 10⁻¹⁰}，　ε = 10⁻⁸
Lcorr = 1 − (1 / |V|) ∑e∈V r̃e

沿连续 batch 的窗口维计算，每条有效连接等权。目标方差过小的连接不参与；预测方差小不直接剔除，以稳定分母保留梯度。没有有效连接或 B<2 时该项为可微零。训练用的是稳定化相关的算术平均，不是评估时的完整扫描 Pearson 和 Fisher-z 汇总。

③ 相邻变化损失 LΔ

Δŷn,e = ŷn+1,e − ŷn,e，　Δyn,e = yn+1,e − yn,e
LΔ = [1 / ((B−1)E)] ∑n=1…B−1 ∑e=1…E (Δŷn,e − Δyn,e)²

约束相邻窗口变化的方向和幅度。步长为 1TR=2.1 秒，未除以 TR，因此是差分而非时间导数。不跨 batch、扫描或缺口计算；B<2 时为可微零。标签窗口重叠约 75%。

本轮四种训练目标

实验标识总损失
mseL = LMSE
temporalL = LMSE + 0.01 Lcorr
deltaL = LMSE + 1.0 LΔ
combinedL = LMSE + 0.01 Lcorr + 1.0 LΔ

全部按验证集逐扫描计算、按被试等权 Fisher 汇总后的 temporal_r 最大值选择检查点，不按最低总训练损失选模。四个标识并不包含纯相关或纯差分训练。
